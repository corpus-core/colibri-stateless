Colibri

Colibri class

High-level Colibri client for proofed RPC calls.

Use rpc to run Ethereum (and compatible) RPC methods with automatic proof generation and verification. Configure provers, ethRpcs, and beaconApis for your network; optionally set storage for native cache.
